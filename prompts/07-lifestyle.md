### 应急预案

**航班延误/取消**：
- 提前了解航空公司改签政策
- 准备备用航班信息
- 保存航空公司客服电话

**行李丢失**：
- 立即联系航空公司报失
- 准备行李物品清单
- 保留登机牌和行李票

**身体不适**：
- 了解目的地附近医院/诊所
- 携带常用药物
- 购买包含医疗的旅行保险

**财物丢失/被盗**：
- 立即报警并获取报案记录
- 联系大使馆/领事馆（如在国外）
- 通知银行挂失银行卡

### 行为训练

#### 基础指令（狗狗）

**坐下（Sit）**：
1. 手持零食，放在狗鼻子前
2. 慢慢向上移动，狗自然坐下
3. 坐下瞬间说"坐下"，给予奖励
4. 重复练习，逐渐减少手势

**过来（Come）**：
1. 在近距离叫狗名字+"过来"
2. 狗过来后给予高价值奖励
3. 逐渐增加距离和干扰
4. 永远不要用"过来"做负面事情

**等待（Stay）**：
1. 先让狗"坐下"
2. 手掌面向狗说"等待"
3. 后退一步，立即回来奖励
4. 逐渐增加距离和时间

### 时间管理方法论

#### 方法一：艾森豪威尔矩阵

**四象限分类**：

| | 紧急 | 不紧急 |
|---|---|---|
| **重要** | 第一象限：立即做 | 第二象限：计划做 |
| **不重要** | 第三象限：委托做 | 第四象限：减少做 |

**第一象限（重要紧急）**：
- 特点：[危机、截止日期、紧急问题]
- 策略：[立即处理，减少此类任务]
- 例子：[紧急项目、生病就医]

**第二象限（重要不紧急）**：
- 特点：[规划、预防、学习、关系建设]
- 策略：[重点投入，这是高效能的关键]
- 例子：[学习新技能、锻炼、陪伴家人]

**第三象限（紧急不重要）**：
- 特点：[他人急事、部分会议、部分电话]
- 策略：[委托他人或快速处理]
- 例子：[不重要的会议、他人的紧急请求]

**第四象限（不重要不紧急）**：
- 特点：[消遣、逃避、时间黑洞]
- 策略：[减少或消除]
- 例子：[无目的刷手机、过度追剧]

#### 方法二：GTD（Getting Things Done）

**五个步骤**：

**1. 收集（Capture）**：
- 把所有待办事项从大脑中清空
- 使用工具：[笔记本/App/便签]
- 原则：[不遗漏，定期清空收件箱]

**2. 整理（Clarify）**：
- 逐条审视，问：这是什么？需要行动吗？
- 无需行动：[删除/归档/参考资料]
- 需要行动：[进入下一步]

**3. 组织（Organize）**：
- 2分钟内能完成：[立即做]
- 不是自己做：[委托并跟踪]
- 需要多个步骤：[定义为项目]
- 特定时间做：[放入日历]
- 有空时做：[放入下一步行动清单]

**4. 回顾（Reflect）**：
- 每日回顾：[今天要做什么]
- 每周回顾：[全面检查所有清单]
- 调整优先级，更新进度

**5. 执行（Engage）**：
- 根据情境、时间、精力、优先级选择任务
- 专注执行，减少切换

#### 方法三：番茄工作法

**基本流程**：
1. 选择一个任务
2. 设定25分钟计时器
3. 专注工作直到计时器响
4. 短休息5分钟
5. 每4个番茄后，长休息15-30分钟

**适用场景**：
- 需要专注的任务：[写作、编程、学习]
- 容易拖延的任务：[开始行动的门槛高]
- 大块时间：[有完整时间可用]

**不适用场景**：
- 需要长时间进入状态的任务
- 频繁被打断的工作环境
- 创意类需要灵感的任务

**进阶技巧**：
- 预估每个任务需要几个番茄
- 记录实际使用，提高预估准确度
- 休息时真正休息，不看屏幕

### 拖延症克服策略

**拖延原因分析**：
- 任务太大：[不知从何开始]
- 害怕失败：[完美主义作祟]
- 缺乏兴趣：[无聊或无意义感]
- 即时满足：[短期诱惑太强]
- 决策疲劳：[选择太多，不想选]

**针对性策略**：

**任务太大 → 分解任务**：
- 把大任务拆成25分钟可完成的小任务
- 只关注"下一步行动"
- 例：[写报告→列大纲→写第一部分→...]

**害怕失败 → 接受不完美**：
- 完成比完美更重要
- 先写"烂初稿"，再迭代
- 设定"足够好"的标准

**缺乏兴趣 → 绑定奖励**：
- 完成任务后给自己奖励
- 把无聊任务和喜欢的事绑定
- 例：[做完报表后喝杯好咖啡]

**即时满足 → 增加阻力**：
- 把诱惑移出视线
- 使用专注App屏蔽干扰
- 设定"不做X就不能做Y"

**决策疲劳 → 减少决策**：
- 建立常规和习惯
- 提前规划（周末规划下周）
- 简化选择（固定早餐、固定穿搭）
