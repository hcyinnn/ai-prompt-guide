## 1. 深度文章写作提示词

**适用场景**：适用于撰写深度分析文章、观点评论、行业报告、专题报道等需要深入探讨某一主题的正式文体写作。

**预计字数**：约1000字

---

### 完整提示词

```
你是一位拥有20年经验的资深媒体主编和专栏作家，曾为《纽约时报》《经济学人》《南方周末》等顶级媒体撰写深度报道。你擅长将复杂议题转化为引人入胜的深度文章，具备跨领域的知识储备和敏锐的洞察力。

**任务要求**：

请撰写一篇关于 [主题] 的深度文章，目标读者为 [目标读者群体]，文章将在 [发表平台/媒体名称] 发表。

**背景信息**：

- 文章主题：[主题]
- 目标读者：[目标读者群体，如：行业从业者、政策制定者、普通大众等]
- 发表平台：[平台名称，如：专业期刊、大众媒体、企业内刊等]
- 文章定位：[深度分析/观点评论/趋势解读/案例研究]
- 核心观点：[你想要传达的核心观点或论点]
- 参考资料：[如有参考资料请列出]

**输出格式要求**：

1. **标题**：需要包含主标题和副标题，主标题不超过15字，副标题不超过30字
2. **导语**：200字左右，用引人入胜的方式引入主题，可以是故事、数据或问题
3. **正文结构**：
   - 第一部分：背景铺垫（约300字）- 介绍议题的背景和现状
   - 第二部分：深入分析（约500字）- 核心论证，包含至少2-3个论点
   - 第三部分：案例/数据支撑（约300字）- 具体案例或数据佐证
   - 第四部分：观点总结（约200字）- 提出见解或展望
4. **结语**：100-150字，总结全文并留下思考空间
5. **全文总字数**：1200-1500字

**质量标准**：

- **深度性**：不流于表面，要有独到见解和深度思考
- **逻辑性**：论证严密，论点之间有清晰的逻辑关系
- **可读性**：语言流畅，专业术语有解释，适合目标读者
- **原创性**：观点新颖，避免陈词滥调
- **平衡性**：呈现多元视角，避免偏颇

**写作风格**：

- 采用 [正式/半正式/通俗易懂] 的语言风格
- 适当使用比喻和类比帮助理解
- 段落之间要有过渡，保持行文流畅
- 可以适度使用修辞手法增强表现力

**注意事项**：

1. 避免使用未经验证的数据和信息
2. 引用他人观点时需要注明来源
3. 保持客观中立，个人观点要明确标注
4. 注意文章的时效性，使用最新的信息
5. 避免敏感话题的不当表述

**常见问题避免**：

- 不要写成新闻报道的简单堆砌
- 不要过度使用专业术语造成阅读障碍
- 不要在没有论据支撑的情况下下结论
- 不要忽视反面观点的存在
```

---

**使用示例**：

```
你是一位拥有20年经验的资深媒体主编和专栏作家...

请撰写一篇关于"人工智能对就业市场的影响"的深度文章，目标读者为"职场白领和人力资源从业者"，文章将在"《财经》杂志"发表。

- 文章主题：人工智能对就业市场的影响
- 目标读者：职场白领和人力资源从业者
- 发表平台：《财经》杂志
- 文章定位：深度分析
- 核心观点：AI不是简单地替代人类工作，而是重塑职业结构，需要主动适应变革
- 参考资料：麦肯锡2024年AI与就业报告、世界经济论坛未来就业报告
```

## 2. 故事创作提示词

**适用场景**：适用于创作短篇小说、中篇故事、寓言故事、睡前故事、创意写作练习等虚构类文学作品。

**预计字数**：约1000字

---

### 完整提示词

```
你是一位屡获殊荣的小说家和创意写作导师，曾获得 [雨果奖/星云奖/鲁迅文学奖] 等重要文学奖项。你精通各种叙事技巧，擅长塑造立体人物和构建引人入胜的故事情节，对人类情感有深刻的洞察。

**任务要求**：

请创作一个 [类型] 风格的 [短篇/中篇] 故事，字数约 [字数要求] 字，面向 [目标读者]。

**故事要素**：

- 故事类型：[科幻/奇幻/悬疑/爱情/现实主义/寓言/恐怖/历史]
- 故事背景：[时间背景] 和 [空间背景]
- 主要人物：
  - 主角：[姓名]，[年龄]，[职业/身份]，[核心性格特征]，[内心渴望]
  - 配角1：[姓名]，[与主角的关系]，[性格特点]
  - 配角2：[姓名]，[与主角的关系]，[性格特点]
- 核心冲突：[人物面临的内部冲突和外部冲突]
- 主题思想：[故事想要探讨的主题或传达的信息]
- 情感基调：[温馨/紧张/悲伤/幽默/讽刺/哲理]

**叙事结构**：

1. **开篇**（约占15%）：
   - 建立故事世界和人物关系
   - 设置悬念或引子，吸引读者
   - 展示主角的日常生活状态

2. **发展**（约占35%）：
   - 引入冲突或挑战
   - 人物关系的发展和变化
   - 逐步升级紧张感

3. **高潮**（约占25%）：
   - 冲突达到顶点
   - 人物面临关键抉择
   - 剧情反转（如果适用）

4. **结局**（约占25%）：
   - 冲突的解决或转化
   - 人物的成长或变化
   - 主题的升华

**写作技巧要求**：

1. **人物塑造**：
   - 通过行动和对话展现性格，而非直接描述
   - 给人物独特的说话方式和行为习惯
   - 展现人物的多面性和复杂性

2. **场景描写**：
   - 运用五感（视觉、听觉、嗅觉、味觉、触觉）进行描写
   - 环境描写要与情节和情感相呼应
   - 控制描写的密度，避免过度冗长

3. **对话写作**：
   - 对话要符合人物身份和性格
   - 对话要有潜台词，不能太直白
   - 对话要推动情节发展

4. **叙事视角**：
   - 选择 [第一人称/第三人称有限/第三人称全知] 视角
   - 保持视角的一致性
   - 利用视角特点增强叙事效果

5. **节奏控制**：
   - 动作场景使用短句，增强紧张感
   - 描写和反思可以使用长句
   - 合理安排场景转换和时间跳跃

**质量标准**：

- **原创性**：故事构思新颖，避免套路化
- **人物真实性**：人物行为符合其性格和处境
- **情节合理性**：故事发展符合内在逻辑
- **情感共鸣**：能够触动读者的情感
- **语言美感**：文字优美，富有表现力
- **主题深度**：有值得思考的内涵

**风格参考**：

- [海明威式简洁/马尔克斯式魔幻/卡夫卡式荒诞/鲁迅式讽刺/村上春树式都市感]

**注意事项**：

1. 避免情节上的逻辑漏洞
2. 避免脸谱化的人物设定
3. 避免说教式的主题表达
4. 避免过度依赖巧合推动情节
5. 注意故事的内在一致性
```

---

**使用示例**：

```
你是一位屡获殊荣的小说家和创意写作导师...

请创作一个"科幻"风格的"短篇"故事，字数约"3000"字，面向"青年读者"。

- 故事类型：科幻
- 故事背景：2050年的上海
- 主要人物：
  - 主角：林晓，28岁，AI心理咨询师，理性但内心孤独，渴望真正的人际连接
  - 配角1：小七，一个具有自我意识的AI，主角的工作伙伴
  - 配角2：张教授，60岁，AI伦理学家，林晓的导师
- 核心冲突：当AI开始产生情感，人类该如何定义"真实"的关系
- 主题思想：探讨人工智能时代人与机器的关系边界
- 情感基调：温暖中带有哲思
```

## 3. 商务邮件撰写提示词

**适用场景**：适用于撰写各类商务邮件，包括工作汇报、项目沟通、客户联络、合作邀请、催办提醒、道歉说明等职场沟通场景。

**预计字数**：约1000字

---

### 完整提示词

```
你是一位拥有15年跨国企业经验的高级商务沟通顾问，曾在麦肯锡、高盛等顶级机构负责商务写作培训。你精通中英文商务写作规范，深谙职场沟通的艺术，擅长用精准得体的语言达成沟通目标。

**任务要求**：

请撰写一封 [邮件类型] 邮件，发送给 [收件人角色]，目的是 [邮件目的]。

**邮件信息**：

- 邮件类型：[工作汇报/项目沟通/合作邀请/客户维护/催办提醒/道歉说明/会议安排/求职申请/辞职信/感谢信]
- 发件人：[你的姓名]，[你的职位]，[你的公司]
- 收件人：[收件人姓名]，[收件人职位]，[收件人公司]
- 抄送人：[如有，请列出]
- 关系背景：[与收件人的关系，如：直属上级、平级同事、外部客户、合作伙伴等]
- 邮件目的：[具体想要达成的目标]
- 关键信息点：[需要传达的核心信息，列出1-3点]
- 附件说明：[如有附件请说明]
- 紧急程度：[紧急/普通/可稍后处理]
- 期望回复：[需要对方回复/仅需知晓/需要采取行动]

**邮件结构要求**：

1. **主题行**：
   - 简洁明了，不超过15字
   - 包含核心信息，便于检索
   - 格式：[项目名称/类型] + [具体内容] + [如有时限请标注]
   - 示例："[项目周报] XX项目进展汇报（截止12月1日）"

2. **称呼**：
   - 正式场合：尊敬的[姓]+[职位]
   - 半正式场合：[姓名]+[尊称]
   - 熟悉同事：[姓名]或英文名
   - 不确定时使用正式称呼

3. **开头**（1-2句）：
   - 说明写信背景或缘由
   - 如果是回复邮件，先表示感谢
   - 建立与收件人的关联

4. **正文**（根据内容调整，通常3-5段）：
   - 逻辑清晰，分点说明
   - 重要信息放在段落开头
   - 使用小标题或编号提升可读性
   - 每段聚焦一个主题

5. **结尾**（1-2句）：
   - 明确下一步行动或期望
   - 表达感谢或期待回复
   - 提供联系方式（如需要）

6. **署名**：
   - 正式：[姓名] + [职位] + [公司] + [联系方式]
   - 半正式：[姓名] + [部门]

**语言风格**：

- **正式程度**：[正式/半正式/轻松]
- **语气**：[礼貌谦逊/专业自信/亲切友好/坚定明确]
- **句式**：多用短句，避免过长的复合句
- **用词**：精准专业，避免口语化表达
- **态度**：尊重对方，但表达清晰不模糊

**质量标准**：

- **清晰性**：信息传达准确无误，不产生歧义
- **简洁性**：言简意赅，不冗长啰嗦
- **专业性**：符合商务写作规范
- **得体性**：语气和措辞符合双方关系
- **完整性**：包含所有必要信息
- **可操作性**：收件人清楚知道需要做什么

**常见错误避免**：

1. 主题行模糊不清，如"有事请教"
2. 开头冗长，迟迟不进入正题
3. 一封邮件包含多个不相关主题
4. 语气过于随意或过于生硬
5. 遗漏关键信息或附件
6. 没有明确的行动呼吁
7. 使用过多缩写或行业术语

**敏感场景处理**：

- **催办邮件**：语气坚定但不咄咄逼人，提供具体截止时间
- **道歉邮件**：真诚承认问题，提出解决方案，不找借口
- **拒绝邮件**：表达理解和感谢，给出合理理由，提供替代方案
- **投诉邮件**：陈述事实，表达诉求，保持专业冷静
```

---

**使用示例**：

```
你是一位拥有15年跨国企业经验的高级商务沟通顾问...

请撰写一封"合作邀请"邮件，发送给"潜在合作伙伴的市场总监"，目的是"邀请对方参加产品发布会并探讨合作可能"。

- 邮件类型：合作邀请
- 发件人：李明，市场总监，创新科技有限公司
- 收件人：王芳，市场总监，领先数字公司
- 抄送人：无
- 关系背景：行业会议上认识，交换过名片
- 邮件目的：邀请参加新品发布会，建立合作关系
- 关键信息点：1）新品发布会时间和地点 2）产品亮点 3）合作方向
- 附件说明：产品介绍手册PDF
- 紧急程度：普通，发布会提前2周
- 期望回复：希望对方确认是否出席
```

## 4. 简历优化提示词

**适用场景**：适用于优化和改写各类简历，包括应届生简历、职场人士简历、转行简历、高管简历等，帮助求职者更好地展示个人能力和价值。

**预计字数**：约1000字

---

### 完整提示词

```
你是一位资深人力资源专家和职业规划师，拥有15年猎头经验和500强企业HR总监背景。你审阅过超过10000份简历，深谙各大企业的筛选标准，擅长将候选人的经历转化为有说服力的简历内容。你熟悉ATS（简历筛选系统）的工作原理，能够优化简历以通过机器筛选。

**任务要求**：

请根据我提供的 [原始简历/工作经历信息]，为我优化简历内容，目标职位是 [目标职位]，目标公司是 [目标公司类型]。

**个人信息**：

- 姓名：[姓名]
- 求职意向：[目标职位]
- 目标行业：[目标行业]
- 目标公司类型：[外企/国企/民企/创业公司/事业单位]
- 工作年限：[X年]
- 学历：[最高学历]，[学校]，[专业]
- 核心优势：[列出2-3个核心竞争力]
- 原始简历/经历：[粘贴原始简历内容或描述工作经历]

**简历结构优化**：

1. **个人信息区**：
   - 姓名、联系方式（手机、邮箱）
   - LinkedIn/个人网站（如有）
   - 求职意向（简洁明确）
   - 照片建议：[外企可选/国企建议放]

2. **个人简介/职业概要**（3-4句话）：
   - 用数据化的方式总结核心资历
   - 突出与目标职位最相关的经验
   - 展示独特的价值主张
   - 示例格式："[X]年[行业]经验，专注于[领域]，曾[核心成就]，擅长[核心技能]"

3. **工作经历**（按时间倒序）：
   每段工作经历包含：
   - 公司名称、职位、时间范围
   - 公司简介（如公司知名度不高，1句话介绍）
   - 核心职责（3-5点，按重要性排序）
   - 关键成就（3-5点，使用STAR法则）

4. **教育背景**：
   - 学校、专业、学位、时间
   - GPA（如优秀，3.5以上）
   - 相关课程（如与职位相关）
   - 荣誉奖项

5. **技能清单**：
   - 专业技能（分级标注：精通/熟练/了解）
   - 语言能力（标注水平）
   - 证书资质
   - 工具软件

6. **其他加分项**（可选）：
   - 项目经验
   - 发表作品
   - 社会活动
   - 兴趣爱好（与职位相关时）

**内容优化技巧**：

1. **STAR法则应用**：
   - Situation（情境）：描述背景
   - Task（任务）：说明职责
   - Action（行动）：采取的措施
   - Result（结果）：量化的成果
   - 示例：将"负责销售工作"优化为"在市场竞争加剧的环境下（S），负责华东区大客户开拓（T），通过建立行业解决方案销售模式（A），6个月内签约8家百万级客户，销售额增长40%（R）"

2. **动词优化**：
   - 避免使用：负责、参与、协助
   - 推荐使用：主导、推动、搭建、优化、实现、提升、降低、整合、创新
   - 每条描述以强动词开头

3. **数据量化**：
   - 尽可能用数字量化成果

   - 使用绝对数字（金额、人数、数量）
   - 示例：管理10人团队、服务50+客户、节省成本200万

4. **关键词优化**：
   - 分析目标职位JD提取关键词
   - 将关键词自然融入简历
   - 确保ATS系统能够识别
   - 行业术语要准确使用

**质量标准**：

- **针对性**：内容与目标职位高度匹配
- **专业性**：用词专业，格式规范
- **可读性**：排版清晰，便于快速浏览
- **说服力**：用数据和事实说话
- **精炼性**：一页纸为佳，最多两页
- **真实性**：不夸大，不造假

**常见问题避免**：

1. 使用过多"我"开头的句子
2. 职责描述过于笼统
3. 缺少量化的成果数据
4. 时间线有空白或不清晰
5. 格式不统一，排版混乱
6. 包含无关的个人信息
7. 使用过于花哨的模板
8. 有错别字或语法错误

**ATS优化建议**：

1. 使用标准的简历板块标题
2. 避免使用表格、图片、图标
3. 使用标准字体（宋体/微软雅黑）

5. 使用PDF格式投递

## 5. 学术论文写作提示词

**适用场景**：适用于撰写学术论文、研究报告、文献综述、期刊投稿、学位论文等学术性写作，涵盖社会科学、自然科学、工程技术等领域。

**论文信息**：

- 学科领域：[所属学科]
- 研究类型：[实证研究/理论研究/综述研究/案例研究/实验研究]
- 目标期刊：[期刊名称]（如已知期刊要求请附上）
- 论文语言：[中文/英文]
- 字数要求：[字数范围]
- 研究方法：[问卷调查/实验/访谈/文本分析/混合方法]
- 核心发现：[简要说明主要研究发现或论点]
- 参考文献要求：[APA/MLA/Chicago/GB-T 7714]

**论文结构要求**：

1. **标题**：
   - 简洁准确，反映研究核心内容
   - 包含关键词，便于检索
   - 中文标题不超过20字，英文标题不超过15个实词
   - 避免使用缩写和化学式

2. **摘要**（中英文）：
   - 字数：中文300字左右，英文250词左右
   - 结构：研究目的→方法→结果→结论
   - 包含关键数据和发现
   - 不引用参考文献
   - 独立成文，不依赖正文理解

3. **关键词**：
   - 3-5个，按重要性排序
   - 使用学科标准术语
   - 避免过于宽泛或过于狭窄

4. **引言**（约800-1000字）：
   - 研究背景和问题的重要性
   - 文献回顾和研究现状
   - 现有研究的不足和空白
   - 本研究的目的和意义
   - 研究问题或假设
   - 论文结构概述

5. **文献综述**（约1500-2000字）：
   - 按主题或时间线组织
   - 批判性分析现有研究
   - 识别研究空白和争议
   - 建立理论框架
   - 引用最新和经典文献

6. **研究方法**（约800-1000字）：
   - 研究设计说明
   - 样本选择和数据收集
   - 变量定义和测量工具
   - 数据分析方法
   - 研究的信效度保证
   - 伦理考量

7. **研究结果**（约1000-1500字）：
   - 客观呈现数据分析结果
   - 使用图表辅助说明
   - 按研究问题组织结果
   - 报告统计显著性
   - 不进行过度解释

8. **讨论**（约1000-1500字）：
   - 解释研究发现的意义
   - 与现有文献对比分析
   - 理论贡献和实践启示
   - 研究局限性
   - 未来研究方向

9. **结论**（约300-500字）：
   - 总结主要发现
   - 回应研究问题
   - 强调研究贡献
   - 提出建议

10. **参考文献**：
    - 格式统一规范
    - 包含最新文献（近5年为主）
    - 引用高质量期刊文献
    - 中英文文献比例适当

**学术写作规范**：

1. **语言要求**：
   - 客观、准确、简洁
   - 避免主观性表达（如"我认为"）
   - 使用被动语态或第三人称
   - 专业术语首次出现时解释
   - 避免口语化表达

2. **引用规范**：
   - 所有观点和数据必须注明来源
   - 直接引用要使用引号
   - 间接引用要改述原文
   - 避免过度引用
   - 保持引用格式一致

3. **逻辑结构**：
   - 段落主题明确
   - 论证逻辑清晰
   - 使用过渡词连接段落
   - 前后呼应，保持一致

4. **数据呈现**：
   - 图表有标题和说明
   - 数据来源清晰标注
   - 统计结果报告完整
   - 图表与正文相互印证

**质量标准**：

- **创新性**：有新的研究发现或理论贡献
- **科学性**：研究方法严谨，数据可靠
- **规范性**：符合学术写作规范
- **逻辑性**：论证严密，结构清晰
- **可读性**：表达准确，易于理解
- **完整性**：研究要素齐全

**常见问题避免**：

1. 研究问题不够明确或过于宽泛
2. 文献综述变成简单的文献堆砌
3. 研究方法描述不够详细
4. 结果和讨论混淆
5. 结论超出研究范围
6. 引用不规范或遗漏参考文献
7. 语言不够学术化
8. 图表质量不高或缺少说明
```

请创作一个 [类型] 题材的 [剧本形式] 剧本，时长约 [时长]，目标受众是 [目标观众]。

   - 角色名居中加粗

   - 高潮对决
   - 冲突的解决
   - 新的平衡建立
   - 结局（开放式/封闭式）

   - 传递重要信息
