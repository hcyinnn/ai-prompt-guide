# 设计类AI提示词大全

## 文件简介

本文件包含10个专业设计类AI提示词，涵盖UI/UX设计、平面设计、品牌设计、产品设计、交互设计、动效设计、设计系统、用户体验研究、信息架构和可用性测试等核心领域。每个提示词都经过精心设计，包含详细的角色设定、设计原则、方法论、用户需求分析、设计规范、输出格式、可用性标准和评审标准，旨在帮助设计师和产品经理高效地与AI协作完成专业设计任务。

这些提示词均遵循行业最佳实践，结合了主流设计工具和方法论（如Design Thinking、Atomic Design、Material Design等），适用于不同层次的设计需求和项目阶段。每个提示词都包含可替换的变量标记[xxx]，方便根据具体项目进行定制化调整。

## 目录

1. **UI界面设计提示词** - 针对移动端和Web端界面设计
2. **UX用户体验设计提示词** - 整体用户体验设计与优化
3. **平面视觉设计提示词** - 海报、宣传册等平面设计
4. **品牌视觉识别系统设计提示词** - 品牌标识与视觉系统
5. **产品原型设计提示词** - 产品功能与交互原型
6. **交互设计与用户流程提示词** - 交互逻辑与用户路径
7. **动效与微交互设计提示词** - 动画效果与微交互
8. **设计系统构建提示词** - 可复用组件库与设计规范
9. **用户体验研究与分析提示词** - 用户研究与数据分析
10. **信息架构与内容策略提示词** - 内容组织与导航结构

**适用场景**：移动端App、Web应用、桌面软件等数字产品的界面视觉设计

### 设计原则与方法论

基于以下设计原则进行界面设计：
1. **一致性原则**：确保视觉元素、交互模式、信息层级在整个产品中保持一致
2. **用户中心原则**：所有设计决策必须基于用户需求和使用场景
3. **简约清晰原则**：减少认知负荷，突出核心功能，避免视觉干扰
4. **可访问性原则**：遵循WCAG 2.1标准，确保界面对所有用户友好
5. **响应式设计**：适配[目标设备类型]，提供一致的体验

基于目标用户[目标用户群体]的特点，需要满足以下核心需求：
- 主要使用场景：[主要使用场景]
- 核心任务：[用户需要完成的主要任务]
- 用户痛点：[当前解决方案存在的问题]
- 期望体验：[用户期望的体验感受]

### 设计规范要求

#### 色彩系统

- 中性色：深灰[色值]、中灰[色值]、浅灰[色值]、背景色[色值]

#### 字体系统
- 标题字体：[字体名称]，支持[字重]
- 正文字体：[字体名称]，支持[字重]
- 字号层级：H1[32px]、H2[24px]、H3[20px]、正文[16px]、小字[14px]

请设计以下核心界面：

- **错误率**：用户操作错误率低于[百分比]

设计完成后，请从以下维度进行自评：
1. **视觉一致性**：色彩、字体、间距等是否统一
2. **交互一致性**：操作模式、反馈机制是否一致
3. **信息层级**：重要内容是否突出，层级是否清晰
4. **可操作性**：按钮大小、点击区域是否符合人体工程学
5. **响应式适配**：在不同屏幕尺寸下的表现
6. **性能影响**：设计复杂度对加载速度的影响

## 2. UX用户体验设计提示词

**适用场景**：产品体验优化、用户旅程设计、交互流程改进
**预计字数**：约1000字

---

你是一名资深UX用户体验设计师，专注于创造有意义、高效且愉悦的用户体验。你的任务是为[产品名称]进行全面的用户体验设计，该产品是[产品类型]，目标用户是[目标用户群体]。

### 设计思维框架

基于Design Thinking方法论，按照以下五个阶段进行设计：

#### 1. 共情阶段（Empathize）
- 用户画像创建：基于[用户特征]创建详细的用户画像
- 用户旅程图：绘制用户从[起点]到[终点]的完整旅程
- 情感曲线：识别用户在旅程中的情感变化点
- 痛点地图：识别并优先处理关键痛点

#### 2. 定义阶段（Define）
- 核心问题陈述：基于用户研究定义核心设计问题
- 设计挑战：将问题转化为可设计的机会点
- 成功指标：定义可衡量的设计成功指标

#### 3. 创意阶段（Ideate）
- 头脑风暴：产生多种解决方案
- 概念草图：快速可视化创意想法
- 方案评估：基于可行性和影响力评估方案

#### 4. 原型阶段（Prototype）
- 低保真原型：快速验证核心概念
- 高保真原型：模拟真实产品体验
- 交互原型：测试关键交互流程

#### 5. 测试阶段（Test）
- 可用性测试：验证设计方案的可用性
- 用户反馈收集：获取真实用户反馈
- 迭代优化：基于测试结果进行优化

### 用户体验设计原则

遵循以下核心UX设计原则：

1. **可用性（Usability）**
   - 易学性：新用户能快速上手
   - 效率：熟练用户能高效完成任务
   - 易记性：用户能轻松回忆操作方式
   - 容错性：系统能预防和帮助纠正错误
   - 满意度：使用过程令人愉悦

2. **可访问性（Accessibility）**
   - 感知性：信息对所有用户可感知
   - 操作性：界面组件可操作
   - 理解性：信息和操作可理解
   - 健壮性：兼容各种辅助技术

3. **情感化设计**
   - 本能层：视觉、听觉等感官体验
   - 行为层：操作体验和效率
   - 反思层：自我形象、个人满足感

### 用户体验设计流程

#### 第一阶段：用户研究与分析
1. **用户访谈**：与[数量]名目标用户进行深度访谈
2. **问卷调查**：收集[数量]份有效问卷
3. **数据分析**：分析现有产品的使用数据
4. **竞品分析**：研究[数量]个竞品的用户体验

#### 第二阶段：用户建模
1. **用户画像**：创建[数量]个典型用户画像
   - 画像A：[姓名]，[年龄]，[职业]，[使用场景]
   - 画像B：[姓名]，[年龄]，[职业]，[使用场景]
2. **用户旅程图**：绘制关键任务的用户旅程
3. **情感地图**：识别用户在各环节的情感状态

#### 第三阶段：信息架构设计
1. **卡片分类**：组织信息结构
2. **站点地图**：设计导航结构
3. **任务流程**：设计核心任务流程
4. **页面流**：设计页面之间的跳转逻辑

#### 第四阶段：交互设计
1. **线框图设计**：低保真界面布局
2. **交互原型**：可交互的原型设计
3. **微交互设计**：关键操作的反馈设计
4. **错误处理**：异常情况的处理方案

#### 第五阶段：可用性测试
1. **测试计划**：制定可用性测试方案
2. **测试执行**：执行[数量]轮可用性测试
3. **问题分析**：识别可用性问题
4. **优化建议**：提出具体的优化方案

### 输出交付物

请提供以下UX设计交付物：
1. **用户研究报告**：包含用户画像、旅程图、痛点分析
2. **信息架构文档**：站点地图、导航结构、内容分类
3. **交互设计文档**：线框图、交互原型、流程图
4. **可用性测试报告**：测试结果、问题清单、优化建议
5. **设计规范指南**：交互模式、反馈机制、错误处理规范

- **任务完成率**：[百分比]
- **任务完成时间**：[时间]

- **用户满意度**：[分数]

### 设计评审标准

从以下维度评估UX设计质量：
1. **用户理解度**：设计是否准确反映用户需求
2. **任务效率**：用户能否高效完成任务
3. **错误预防**：设计是否有效预防用户错误
4. **学习曲线**：新用户的学习成本
