## 📖 项目简介

本项目是一个系统化的AI提示词大全，旨在帮助用户更高效地与AI大语言模型（如ChatGPT、Claude、Gemini等）进行对话。每个提示词都经过精心设计，包含详细的上下文设定、角色定义、输出格式要求和质量标准，确保你能获得高质量的AI回复。

### ✨ 特点

- 🎯 **专业性强**：每个提示词都针对特定场景精心设计
- 📏 **内容丰富**：每个提示词约1000词，包含详细的指导说明
- 🔄 **可定制性**：提供模板变量 `[xxx]`，方便用户根据需求修改
- 📚 **分类清晰**：按使用场景分为10+个类别，便于查找
- 🌍 **中英双语**：部分提示词提供中英文版本
- 💡 **实用性强**：每个提示词都附带使用场景和示例

## 📖 使用指南

### 1. 选择提示词
根据你的需求，从对应的分类中选择合适的提示词模板。

### 2. 填写变量
将提示词中的 `[xxx]` 变量替换为你的具体内容。

### 3. 发送请求
将修改后的提示词发送给AI助手。

### 4. 迭代优化
根据AI的回复，继续优化提示词或追问细节。

## 💡 提示词编写技巧

### ✅ 好的提示词特征
- **明确具体**：清楚说明你的需求和期望
- **提供上下文**：给出足够的背景信息
- **指定格式**：说明你希望的输出格式
- **设定角色**：让AI扮演特定角色
- **限制范围**：明确任务的边界
- **提供示例**：给出参考示例

### ❌ 避免的写法
- 模糊不清的请求
- 缺乏上下文的提问
- 过于宽泛的问题
- 没有格式要求的输出
